# Maiac: Registration Table

AI marketing automation and consultancy. Version 1 of the Registration Table landing page.

**Website:** https://flaviusapop.github.io/maiac-registration/

This is a self-contained static website. Open `index.html` directly or serve it with any static web server. Images, fonts, styles and interaction code are embedded, so there is no package installation or build step.

GitHub Pages publishes the root of the `main` branch. Contact actions open an email draft in the visitor's email application.
